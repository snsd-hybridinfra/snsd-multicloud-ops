# Prerequisites

## Required Repository State

- PowerShell can run the local validator.
- The S009 scenario and evidence directories exist.
- The inventory and topology model directories are readable.

## Not Required

- A DNS server, zone, resolver, hosts file, or real record.
- Network or host access.
- AWS, Azure, OpenStack, Kubernetes, or public DNS authentication.
- Credentials, keys, kubeconfig, `clouds.yaml`, openrc, or account identifiers.

S007 and S008 supply the preceding inventory and bastion model context.
