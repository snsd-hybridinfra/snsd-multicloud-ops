# Objective

Validate the baseline EVE-NG on-prem network routing structure required for later multi-cloud operations scenarios.

This scenario focuses on the routing model between these on-prem zones:

- Management Zone
- Bastion Zone
- Transit Zone
- Internal Server Zone
- Monitoring Zone

Success means the scenario defines how to prove router reachability, inter-zone routing, route table visibility, and missing-route failure conditions without implementing firewall rules or changing live infrastructure.
