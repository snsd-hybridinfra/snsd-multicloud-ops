# Prerequisites

## Required Previous Scenarios

- `S001-control-plane-toolchain-validation` is planned and identifies the local toolchain needed to collect evidence.

## Required Tools

- Access to the repository workspace.
- Access to planned EVE-NG topology documentation or exported topology summary.
- Access to sanitized router configuration snapshots.
- A shell capable of recording command plans in `commands.md`.

## Required Access Assumptions

- EVE-NG lab access, if used later, is approved and non-production.
- Validation can use placeholders until lab execution is authorized.
- No credentials, private keys, tfstate, kubeconfig files, or account-specific values are needed.
