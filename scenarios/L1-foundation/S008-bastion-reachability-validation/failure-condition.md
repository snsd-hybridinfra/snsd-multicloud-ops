# Failure Condition

## Critical Failure Conditions

- A required model file, access path, target alias, address placeholder, or policy statement is missing.
- A numeric IP, username, password value, token value, credential assignment, key path, access key, account ID, subscription ID, tenant ID, or UUID is detected.
- The validator contains or executes SSH, Ansible, network, cloud, Kubernetes, OpenStack, or EVE-NG access.
- Documentation implies that a placeholder path proves real connectivity or instance existence.

Any critical failure produces a non-zero exit and must be documented without exposing the unsafe value.
