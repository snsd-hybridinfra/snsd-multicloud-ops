# Scope

## Included

- Static baseline, datasource YAML, dashboard JSON, nine-area matrix, commands, and three samples.
- Ten required panel titles with placeholder datasource and query metrics.
- Dashboard search/detail and datasource-list JSON parsing.
- Optional explicit unauthenticated `/api/search` and `/api/datasources` checks.
- Credential/token/cookie/datasource/TLS, endpoint, domain/address, UID/identity, and execution safety.

## Excluded

- Grafana start/reload/config change or dashboard import/create/update/delete.
- Default live query/network access and authenticated API access.
- Real Grafana/Prometheus/cluster URLs, UIDs, organization/user IDs, credentials, tokens, cookies, datasource secrets, TLS material, domains, or addresses.
- S020/S025/S027/S028/S030 responsibilities.
