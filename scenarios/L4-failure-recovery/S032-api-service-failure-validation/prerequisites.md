# Prerequisites

## Static

- PowerShell, validator, three runbook artifacts, and nine sanitized samples.
- No kubectl, curl, network, kubeconfig, credential, or fault injection is required.

## Optional live modes

- LiveKubectl: explicit approval, kubectl, Namespace, DeploymentName, ServiceName, and read-only lab access.
- LiveHttp: explicit approval and a non-sensitive ApiHealthUrl.

Manual destructive collection is separate and limited to a disposable namespace.
