# Scope

## Included

- Static runbook, commands, ten-phase criteria, and five sanitized samples.
- Pre-failure healthy Pods, manual event, original inactivity, replacement readiness, rollout, endpoint continuity, and timing placeholder.
- Optional read-only deployment/Pod/rollout/endpoint queries.
- Kube credential-file, endpoint/domain/address, token/certificate/key/secret, and destructive-execution safety.

## Excluded

- Automated or validator-executed Pod deletion/fault injection.
- Apply, patch, edit, scale, restart, cordon, drain, taint, or any cluster mutation.
- Production testing, real namespace/cluster/endpoints/IPs/UIDs, kubeconfig, tokens, certificates, keys, or secrets.
- S021/S022/S032/S035/S040 responsibilities.
