# Scope

## Included

- Static runbook, commands, twelve-phase criteria, debug-only Ansible placeholder, metric documentation, and six samples.
- Pre-failure threads/lag, manual fault marker, failure signal, Primary availability, recovered threads/lag, and catch-up.
- Dump, credential, connection-string, address, key, secret, and executable-command safety.

## Excluded

- Database/monitoring connection, SQL, service stop/start, Ansible execution, replication reset/change, promotion, failover, or automatic recovery.
- Real hosts, IPs, credentials, GTIDs, binlog values, database names, dumps, production-grade HA, or live evidence.
