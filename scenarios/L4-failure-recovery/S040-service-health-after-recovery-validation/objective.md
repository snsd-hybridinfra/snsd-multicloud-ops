# Objective

S040 validates the planned evidence model for judging end-to-end service health after recovery activities have completed.

The scenario defines how to review Web and API responses, Ingress, Nginx Reverse Proxy, load balancing health, MariaDB state references, Prometheus target status, Grafana visibility, Blackbox probe success, and a final evidence-based recovery judgment.

This scenario remains documentation-only until execution is explicitly approved. It does not implement recovery scripts, automatic DR, production-grade HA, automatic cross-cloud failover, enterprise recovery orchestration, credentials, secrets, kubeconfig files, tfstate, or live health output.
