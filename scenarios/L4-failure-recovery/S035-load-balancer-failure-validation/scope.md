# Scope

## Included

- Static runbook, commands, eleven-phase criteria, symbolic metrics, response matrix, and ten samples.
- LB/backend pre-state, manual fault, LB/client failure, backend isolation, manual recovery, post health, bypass/rollback, and timing.
- Optional explicit unauthenticated status-only LiveHttp.

## Excluded

- Automated stop/start, Nginx/Ingress/cloud LB/DNS/routing/configuration change, failover, or production execution.
- Credentials, cookies, authorization values, API keys, response bodies, payloads, real URLs/domains/IPs, or TLS material.
