# Scope

## Included

- Static runbook, commands, ten-phase criteria, restore policy, debug-only Ansible, six log samples, and one manifest.
- Backup reference, checksum, disposable target, manual restore sample, metadata, consistency, completion, rollback, and S040 linkage.

## Excluded

- Restore execution, SQL import, archive extraction, backup download, object-storage query, database/Ansible access, production target/data, or S040 live health testing.
- Real artifacts, dumps/archives, paths/storage targets, rows, credentials, connection strings, keys, secrets, or account values.
