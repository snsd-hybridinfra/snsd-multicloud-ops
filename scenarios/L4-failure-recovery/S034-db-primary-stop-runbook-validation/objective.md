# Objective

S034 validates the manual runbook response model for a MariaDB Primary stop event in the On-Prem Internal Server Zone database layer.

The scenario defines how to document pre-failure state, simulate a Primary stop with placeholder commands, detect Primary write-path failure, verify Replica state during the outage, document manual decision points, restore the Primary, and review replication state after recovery.

This scenario remains documentation-only until execution is explicitly approved. It does not implement MariaDB configuration, automatic failover, HA database behavior, database passwords, credentials, or live outage evidence.
