# Scope

## Included

- Static runbook, commands, placeholder alert rule, eleven-phase criteria, response matrix, and ten samples.
- Pre-UP, manual fault, DOWN/up=0/firing, manual recovery, post-UP/up=1/resolved, and timing review.
- Optional explicit read-only LivePrometheus API queries and sensitive-content safeguards.

## Excluded

- Prometheus/exporter start, stop, reload, rule modification, automatic fault injection/recovery, Alertmanager routing, or production execution.
- Credentials, cookies, authorization values, webhooks, raw API responses, real URLs/domains/IPs/scrape targets, or TLS private keys.
