# Failure Condition

Failure includes missing artifacts/policy metadata, ambiguous misconfiguration or rollback, missing detection/impact, unsafe post-state, absent rollback proof, modification commands presented as normal executable workflow, cloud/Kubernetes/firewall/Terraform execution, real cloud ID/resource value, IP/CIDR/domain, credential, token, cookie, authorization value, key, or secret. Placeholder-only expiry is WARN.
