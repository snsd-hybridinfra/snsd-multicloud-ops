# Scope

## Included

- Static runbook, command reference, ten-type criteria, nine-case rollback matrix, non-production policy, and seven samples.
- Pre-change least privilege, manual unsafe sample, detection/severity, impact, manual rollback, restricted post-state, and final summary.
- Exception owner/reason/expiry/approval/change-reference/rollback requirements and concrete identifier/network/secret safety.

## Excluded

- Cloud CLI, SG/NSG/OpenStack SG/firewall/NetworkPolicy/Terraform/routing modification or live testing.
- Automatic blocking, SOAR, WAF, IDS/IPS, EDR, production emergency automation, or new security tooling.
- Real identifiers, accounts/projects, resource names, IPs/CIDRs/domains, credentials, tokens, cookies, authorization values, keys, or secrets.
