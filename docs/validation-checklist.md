# Repository Validation Checklist

- [ ] Canonical package flow is valid and package IDs are unique.
- [ ] Package metadata and capability references resolve.
- [ ] Implementation, local validation, runtime validation, acceptance, evidence, and maturity states remain separate.
- [ ] CV, RV, and SCH predecessor rules hold.
- [ ] Phase 1 remains truthful.
- [ ] No active numbered scenario path, matrix, registry, aggregate tool, or identifier exists.
- [ ] Package evidence remains present and sanitized.
- [ ] All JSON-compatible YAML and JSON parse.
- [ ] Schemas and presentation views synchronize.
- [ ] Read-only validators do not mutate repository authorities.
- [ ] No tracked `.runtime/**`, secret, private key, account value, or personal data exists.
- [ ] `git diff --check` passes.
