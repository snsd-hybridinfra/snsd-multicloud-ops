# KISA 매핑 범위와 제한

2026 가이드의 Unix, Windows, 웹 서비스, 보안 장비, 네트워크 장비, 제어시스템, PC, DBMS, 이동통신, Web Application, 가상화 장비와 클라우드 도메인을 출처 범위로 등록했다.

현재 seed는 Phase 1의 ID/NET/VIS와 향후 APP/DATA 및 클라우드 확장을 위한 검증된 대표 항목을 포함한다. 적용 여부는 대상 제품·버전·운영 영향·예외·rollback 검토 전에는 확정하지 않는다.

다음 추론을 금지한다.

- 매핑 존재 = 통제 구현
- 구성 존재 = 런타임 검증
- KISA item 통과 = KISA 준수 또는 인증
- 단일 실험실 결과 = 전사·다중환경 검증
- 설계 또는 도구 설치 = L3/L4 성숙도
