## Queue use

1. Select the smallest cohesive dependency-ready package, not an isolated product.
2. Pass the applicable phase gate before implementation or runtime testing.
3. Recalculate order when evidence changes a dependency, applicability, or blocker.
4. Never promote status or maturity from queue position alone.
5. Use backlog IDs until future scenario creation is explicitly approved.
