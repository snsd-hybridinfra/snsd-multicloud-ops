# Naming Rules

## Capability IDs

Use canonical source IDs exactly as `ZT-<source-number>`, for example `ZT-3.1.1`.

## Package IDs

Use `ZT-<DOMAIN>-<NNN>`. Existing authoritative Phase 1 packages retain their IDs.

## Package validation IDs

When a stable test identifier is required, use `<PACKAGE-ID>-T<NN>`, such as `ZT-ID-001-T01`.

## Action IDs

Governance and recovery actions use an approved descriptive identifier such as `ZT-SCN-RETIRE-001`.

## Prohibited naming

- A successor numbered scenario series
- Unregistered capability or package IDs
- IDs that imply implementation, validation, compliance, or maturity
- Credentials, host identities, account values, or personal information in names
