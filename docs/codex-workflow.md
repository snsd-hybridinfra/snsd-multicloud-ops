# Codex Workflow

1. Read scope, exclusions, package metadata, capability authority, and relevant governance.
2. Confirm the requested action, protected scope, source authority, and Git baseline.
3. Implement the smallest package-oriented change.
4. Add or update positive and negative tests without touching a live target unless separately authorized.
5. Record only sanitized evidence and explicit limitations.
6. Run read-only package, architecture, runbook, synchronization, structure, safety, and unit-test validation.
7. Inspect the explicit staging allowlist, diff, runtime tracking, secrets, privacy, and repository mutation.
8. Commit and push only when the action explicitly authorizes it and all gates pass.

Do not use a numbered scenario as work authority or progress measurement.
