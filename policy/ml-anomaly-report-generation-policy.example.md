# ML Anomaly Report Generation Policy — Non-Production Example

Reports use metric-only retired-numbered-case evidence, reference retired-numbered-case, map to retired-numbered-case, and include anomaly/warning/review-required counts, evidence references, and human review. SIEM, Wazuh, EDR, raw logs, packet captures/payloads, malware detection, threat hunting, LLM-based final decisions, automated blocking, SOC auto-incident creation, real identifiers, credentials, and secrets are prohibited.
