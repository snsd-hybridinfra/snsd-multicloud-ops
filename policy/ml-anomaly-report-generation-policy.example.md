# ML Anomaly Report Generation Policy — Non-Production Example

Reports use metric-only S048 evidence, reference S047, map to S050, and include anomaly/warning/review-required counts, evidence references, and human review. SIEM, Wazuh, EDR, raw logs, packet captures/payloads, malware detection, threat hunting, LLM-based final decisions, automated blocking, SOC auto-incident creation, real identifiers, credentials, and secrets are prohibited.
